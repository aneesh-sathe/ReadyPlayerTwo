Complete female angel 2D navigation sprite set

64 separate transparent RGBA PNG files, all on a 512 x 512 canvas.
Hair is jet black with charcoal highlights.

Contents:
- 12 static emotion/direction poses
- 8-frame walk-left loop
- 8-frame walk-right loop
- 8-frame glide-up loop, viewed from behind
- 8-frame glide-down loop, viewed from the front
- 4-frame hover loop
- 4-frame left and right takeoff transitions
- 4-frame left and right landing transitions

Use animation-manifest.json for recommended order, frame rate, loop behavior, and anchor points.
