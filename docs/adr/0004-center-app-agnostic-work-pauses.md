# Center app-agnostic work pauses

For v2, the Companion may serve people across professions and applications during inferred non-disruptive pauses rather than depend on one AI agent or app. Agent Wait is one example, not the defining case. This broadens the proactive experience beyond developers while requiring conservative availability inference so active work is never interrupted. ADR-0012 defers this behavior beyond v1.
