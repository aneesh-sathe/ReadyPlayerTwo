# Learn from explicit feedback

For v2, the Companion may personalize Check-ins using explicit, lightweight feedback rather than silently classifying screen content. Dismissing a Check-in remains immediate and reveals an optional Dismissal Reason dropdown; an unlabeled dismissal is only a weak signal, while a supplied reason can shape a Check-in Preference. ADR-0012 defers this behavior beyond v1.
