# Auto-update a bounded Companion Memory

A future memory-enabled release may automatically curate a local, user-auditable `memory.md`, including relevant personal facts that may be sensitive. Core Memory preserves stable facts, Pattern Memory adapts with behavior, and Recent Memory expires or summarizes first. The complete file is capped at 10,000 characters, compaction starts at 8,000, and its result must be below 6,000. This Memory Budget forces deliberate retention but remains a relevance control rather than a privacy control; backend exposure and storage protection remain subject to the security review.

Companion Memory is excluded from v1.
