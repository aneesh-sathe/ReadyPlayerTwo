# Ship v1 as summon-only

The first release will be a Summon-Only Experience with Roaming Presence: the Companion remains visible and moves silently by default, but it never initiates contact and every Voice Session begins with an explicit person action. Park and Hide give the person direct control over that presence. V1 is also a Screen-Blind Experience, excluding screen content, Check-ins, Inactivity monitoring, availability inference, proactive cadence, Presence Signals, and dismissal learning while retaining polished desktop-wide character motion and OpenAI Realtime voice conversation.
