# Make the Companion desktop-wide

The Companion will inhabit a desktop-wide stage rather than an AI agent application's window. This adds platform integration and interaction complexity, but preserves the defining experience of an office mate that can move independently around the person's workspace instead of feeling like an in-app widget.

In v1, the Desktop Stage uses display bounds as terrain but does not enumerate, react to, collide with, or climb application windows. Transparent Companion UI remains click-through outside the visible character and conversation controls.
