# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `question` | Maintainer evaluation required |
| `needs-info` | `question` | Waiting for reporter information |
| `ready-for-agent` | `enhancement` | Fully specified and ready for an AFK agent |
| `ready-for-human` | `help wanted` | Human implementation required |
| `wontfix` | `wontfix` | Will not be actioned |

Use only the mapped GitHub label when an engineering skill names a canonical role.
