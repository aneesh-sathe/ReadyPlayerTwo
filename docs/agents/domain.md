# Domain docs

This repository uses a single domain context.

Before planning, testing, implementing, or triaging:

1. Read the root `CONTEXT.md`.
2. Read relevant decisions under `docs/adr/`.
3. Use glossary terms exactly in code, tests, issues, and documentation.
4. Surface an ADR conflict explicitly instead of silently overriding it.

The root `CONTEXT.md` defines the shared language. `docs/adr/` contains system-wide decisions.
